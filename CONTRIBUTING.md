# Contributing

Keep image decoding and rendering outside the main actor. Validate dimensions and adjustment ranges before rendering; preserve original bytes and fail visibly on invalid recipes. Add meaningful regression tests for persistence or rendering changes.

Run Debug and Release core tests, Mac and iPad builds, and the native workflow for interface changes. Identify checks that need physical hardware or camera files. Do not commit personal photographs, signing identities, provisioning profiles, or credentials. The synthetic DNG and aperture icon are original project assets.
