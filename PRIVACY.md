# Privacy

RAW Photo Studio has no account, telemetry, cloud library, or app network permission. It copies only a RAW file you select into its local Application Support library and saves adjustments beside it. The original at its source location is never modified.

Copied originals retain embedded camera and location metadata. Exported JPEGs contain rendered pixels without the source metadata. The app's sandbox permits reading and writing files selected through system panels so that explicit import and export work; it does not grant broad access to folders or the Photos library.

The app is not an encrypted vault. Local storage follows normal device storage and backup protections. Keep backups of original files and recipes. Failed recipe reads preserve files instead of replacing the library.
